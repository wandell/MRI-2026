# Code

This directory holds the published, self-contained HTML for the course's MATLAB
tutorials — one `.html` file per tutorial, with figures and any movies already
embedded as base64. Nothing runnable lives here.

The tutorial source (`.m`/`.mlx`), the data it loads, and the shared teaching
utility functions live in the separate `teachmri` GitHub repository
(`~/Documents/MATLAB/teach/teachmri` locally). Readers who want to run the
tutorials themselves should get them from there.

See `.github/skills/matlab-evaluation/SKILL.md` for the edit → verify →
publish → copy-here workflow.
